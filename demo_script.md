# Demo Recording Script

## Scene 1 — Introduce the agent
Say:
“I'm demonstrating my Binance AI Spread Agent. It scans multiple markets, finds the largest Spot/Futures discrepancy, explains it, and requires confirmation before trading.”

## Scene 2 — Run the prompt
Paste the demo prompt and show the live Binance MCP tool calls/results.

## Scene 3 — Analysis
Show the ranked BTC/ETH/SOL table and the selected opportunity.

## Scene 4 — Confirmation gate
The agent must stop and ask for confirmation. Do not skip this moment.

## Scene 5 — Execute
Give explicit confirmation and execute a small, controlled trade using the Binance Agent OS sub-account.

## Scene 6 — Verify
Show the filled/confirmed order result and order ID.

## Scene 7 — Close
Say:
“The key feature is the controlled agentic workflow: market discovery, reasoning, human approval, execution, and verification.”
